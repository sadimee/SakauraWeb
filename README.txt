# Sakura — Discord Companion Website

## Project files
- `index.html` — landing page
- `style.css` — responsive design, light/dark themes and animations
- `script.js` — commands, shop demo, wallet, marriage demo and theme switch
- `favicon.svg` — browser tab icon
- `assets/` — put your existing `sakura-girl.webp` and `sakura-couple.webp` images here

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Important
The coins, shop and marriage preview are local demos only. They are not connected to a live Discord bot or database. No Discord invite or OAuth login is fabricated.
